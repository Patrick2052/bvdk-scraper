# BVDK Scraper - A Webscraper to scrape powerlifting competitions and their info from the official bvdk.de website

Written in python and using selenium to emulate a browser and extract all competitions from the official german powerlifting federation website.

It uses pydantic to make sure data has the right structure and saves the data to a Postgres database, to be used for further analysis.
